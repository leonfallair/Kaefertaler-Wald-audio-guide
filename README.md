# Kaefertaler-Wald-audio-guide

I developed this web app during my internship at the city of Mannheim.It contains a web map application that provides information about the Mannheim city forest with location markers. It is based on maplibre and the OSM Streets map is connected via Maptiler. Further information can be found in the code files and the documentation. The webpage can be viewed under the link https://leonfallair.github.io/Kaefertaler-Wald-audio-guide/

## Functions

* Interactive map view with location markers
* Audio information for selected points
* Offline-capable progressive web app
* Based on open-source technologies
